# Singularis

A Python-based 3D black hole simulator focused on visualizing gravitational effects, accretion disks, and gravitational lensing.

## About the Project

Singularis is a personal project aimed at exploring the physics and visualization of black holes through programming, numerical methods, and 3D graphics.

The initial implementation will focus on a non-rotating Schwarzschild black hole, with plans to introduce relativistic ray tracing and more advanced physical models over time.

## Goals

- Simulate a black hole's event horizon.
- Visualize particle motion and orbital dynamics.
- Build a 3D accretion disk.
- Implement gravitational lensing and light deflection.
- Provide an interactive camera and simulation controls.
- Explore relativistic effects through numerical methods.
- Investigate rotating black holes in future versions.

## Technologies

- **Python** — core logic and physics calculations.
- **Panda3D** — 3D rendering and camera controls.
- **NumPy** — numerical calculations and vector operations.
- **SciPy** — numerical integration of differential equations.

## Scientific Scope

The project will be developed incrementally, starting with simplified Newtonian models and progressing toward general-relativistic calculations.

Visual approximations will be distinguished from physically calculated effects. The simulator is an educational and exploratory project, not a complete astrophysical simulation.
